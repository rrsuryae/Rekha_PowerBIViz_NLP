# PowerBI Custom Visual - NLP by OpenAI GPT 

Welcome to the PowerBI custom visual that creates NLP (Natural Language Processing) analysis for the data on your dashboards! This project is designed to enhance your PowerBI dashboards by using NLP analysis from OpenAI's GPT to understand your data. Now you can ask questions about your data and get intelligent and insightful answers!

Also this compares the capabilities of the Power BI inherent features like QnA, Narrative and the Custom Visual(LLM powered - Open AI/gpt-mini-4o).

1) The observation is that QnA could answer only specific to the data and its outcome wasnt generative in nature. 
2) While Narrative summarized very well statistically about the visual graph.
3) The Custom Visual powered by LLM - seemed to reason and answer the query based on the context data supplied to it. But it is noticed that it was still hallucinating, due to the inherent nature of the GPT.
   
This project can be made enterprise scale by connecting the Custom Visual (powering) by connecting to an in-house domain fine tuned RAG/LLM, with guard rails - exposed behind an API gateway!
